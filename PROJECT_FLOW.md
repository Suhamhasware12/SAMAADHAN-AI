# SAMAADHAN AI - Project Workflow

## Overview

SAMAADHAN AI follows a capability-driven workflow that connects societal problems with the stakeholders and capabilities required to solve them.

## 1. Problem Submission

A user submits a societal challenge with details such as:

- Problem title
- Problem description
- Category
- Location
- Problem source
- Supporting evidence

## 2. AI-Assisted Analysis

The system analyses the submitted challenge and identifies its problem domain and the capabilities required for solving it.

## 3. Capability Extraction

The system identifies the capabilities required for a multidisciplinary solution.

For example, a crop disease problem may require:

- Agriculture / Plant Pathology
- AI/ML + Computer Vision
- IoT / Field Monitoring
- Hardware / Prototype Development

## 4. Capability-Based Matching

The platform compares the required capabilities with the capabilities registered by universities, experts and industry partners.

## 5. Collaboration Gap Detection

If one or more required capabilities are unavailable, the system identifies the missing capability.

## 6. Partner Recommendation

Based on the missing capability, the platform recommends the appropriate type of partner.

For example:

**Missing Hardware Capability → Industry / Hardware Partner**

## 7. Collaboration Formation

Relevant stakeholders are composed into a multidisciplinary collaboration team.

## 8. Progress Tracking

The platform tracks the collaboration journey through stages such as:

- Challenge Analysed
- Capabilities Identified
- Collaboration Formed
- Solution Development
- Field Pilot
- Wider Deployment

## Core Workflow

**Problem → Required Capabilities → Capability Matching → Gap Detection → Partner Recommendation → Collaboration Team → Progress Tracking**
